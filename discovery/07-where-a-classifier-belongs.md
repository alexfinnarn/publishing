You said a structured output is a classifier that claims the interesting
work already happened, and a language template is the same type without
a parser. The remainder is the work. You have to look.

This folder already classifies by hand: surfaces and content types in
[ontology.md](../ontology.md), questions versus types in
[questions.md](../questions.md), discovery versus `site/` versus
`books/`. Those are types. A model can be asked to inhabit them.

Background is still
[references/three-ideas.md](../references/three-ideas.md): no total
classifier, you cannot type the user, looking is the method for
idea-work. The last note is
[You have to look](06-you-have-to-look.md).

Tomorrow, write into this:

**Name one place in this project where you would let a classifier act —
what it would type, who still looks, and what it is forbidden to
promote.**

Not a stack. Not how classifiers could help publishing. One edge: a
tag, a template, a pass/fail, a surface. What is reducible there. What
a wrong promotion would steal — a note becoming an essay, an essay
becoming an offer, a filled template becoming the next call's only
input.

Write under the question. Ignore the prompt if a better sentence shows
up.
