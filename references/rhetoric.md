# Rhetoric pointers

Reference, not a checklist. Nothing has to pass through this before it gets
written. Useful when a piece is already stuck.

**Stasis** — the order to take a topic apart in: did it happen (fact), what
do we call it (definition), good or bad and who benefited (quality), what
should be done (policy). Hermagoras; Quintilian. Short start: Purdue OWL,
"Stasis Theory."

**Toulmin** — claim, grounds, warrant, rebuttal. *The Uses of Argument*.
The rebuttal is the useful half: what would make this false.

**First principles** — what must be true for the rest to hold. Aristotle,
*Posterior Analytics* I; opening of the *Metaphysics*. An *archē* is
assumed, not proved from something more basic.

**Audience** — the rhetorical situation: exigence, audience, constraints.
Who has to live with the claim: you tonight, a stranger, a sequential reader.

**Who benefits** — sociology of knowledge; Bourdieu on distinction.
